8. Open-source licenses

No blockers

The license data of all 88 packages in the app's environment and all 108 in the browser worker's environment was read, plus the bundled scripts, font and icons. Everything is permissive (MIT, BSD, Apache 2.0, MPL 2.0 used unmodified, SIL OFL for the font). There is no copyleft code that would force the source to be published, even if the tool is sold or offered as a service.

Paperwork to finish: MIT requires the copyright notice to travel with every copy. The bundled Alpine.js file and the compiled Tailwind CSS (which embeds Tailwind's Preflight base styles) ship without it, so add a THIRD_PARTY_NOTICES file with their MIT notices, the Apache-2.0 notice for Material Symbols and a pointer to the Roboto license. Also decide who owns the project's own code (normally the employer); it has no LICENSE file yet.
